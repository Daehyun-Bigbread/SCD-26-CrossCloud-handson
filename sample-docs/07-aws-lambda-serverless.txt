AWS Lambda와 서버리스 아키텍처

AWS Lambda는 서버를 프로비저닝하거나 관리하지 않고 코드를 실행할 수 있는 컴퓨팅 서비스입니다.

AWS Lambda 핵심 개념:
- 함수(Function): Lambda에서 실행되는 코드 단위입니다.
- 트리거(Trigger): 함수를 호출하는 이벤트 소스입니다 (API Gateway, S3, DynamoDB, SQS 등).
- 런타임(Runtime): 코드가 실행되는 언어 환경입니다 (Python, Node.js, Java, Go, .NET, Ruby, Rust).
- 레이어(Layer): 여러 함수에서 공유하는 라이브러리나 의존성을 패키징합니다.
- 콜드 스타트(Cold Start): 함수가 처음 호출되거나 오랜 시간 사용되지 않았을 때 초기화에 걸리는 시간입니다.

Lambda의 장점:
1. 비용 효율성: 실행 시간(밀리초 단위)과 요청 수에 따라서만 과금됩니다. 유휴 시간에는 비용이 발생하지 않습니다.
2. 자동 확장: 들어오는 요청에 따라 자동으로 함수 인스턴스가 확장됩니다.
3. 운영 부담 최소화: OS 패치, 서버 관리, 용량 계획 등을 AWS가 처리합니다.
4. 다양한 통합: 200개 이상의 AWS 서비스 및 SaaS 애플리케이션과 통합됩니다.

Lambda 제한사항:
- 실행 시간: 최대 15분으로 제한됩니다.
- 메모리: 128MB ~ 10,240MB (10GB) 범위에서 설정 가능합니다.
- 패키지 크기: 압축 시 50MB, 압축 해제 시 250MB까지 허용됩니다.
- 동시 실행 수: 리전별 기본 1,000개 (상향 요청 가능).

서버리스 아키텍처 구성 요소:
- API Gateway: RESTful API 또는 WebSocket API의 엔드포인트를 관리합니다.
- DynamoDB: 서버리스 NoSQL 데이터베이스로, Lambda와 함께 자주 사용됩니다.
- S3: 정적 파일 저장 및 이벤트 트리거로 활용됩니다.
- SQS/SNS: 비동기 메시징 및 이벤트 기반 아키텍처를 구현합니다.
- Step Functions: 복잡한 워크플로를 시각적으로 설계하고 관리합니다.

요금 체계:
- 요청 수: 월 1백만 건까지 무료, 이후 100만 건당 $0.20.
- 실행 시간: 월 40만 GB-초까지 무료, 이후 GB-초당 $0.0000166667.
- 프리 티어는 12개월 한정이 아니라 영구 무료입니다.
