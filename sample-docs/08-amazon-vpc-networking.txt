Amazon VPC와 네트워크 기초

Amazon VPC(Virtual Private Cloud)는 AWS 클라우드에서 논리적으로 격리된 가상 네트워크를 정의할 수 있게 해주는 서비스입니다.

VPC 핵심 구성 요소:
1. VPC: 사용자가 정의하는 가상 네트워크입니다. CIDR 블록(예: 10.0.0.0/16)으로 IP 주소 범위를 지정합니다.
2. 서브넷(Subnet): VPC 내의 IP 주소 범위를 나누는 단위입니다. 퍼블릭 서브넷과 프라이빗 서브넷으로 구분합니다.
3. 인터넷 게이트웨이(IGW): VPC와 인터넷 간의 통신을 가능하게 합니다.
4. NAT 게이트웨이: 프라이빗 서브넷의 리소스가 인터넷에 접근할 수 있게 합니다 (인바운드는 차단).
5. 라우팅 테이블: 네트워크 트래픽의 방향을 결정하는 규칙 집합입니다.
6. 보안 그룹(Security Group): 인스턴스 수준의 가상 방화벽입니다. 인바운드/아웃바운드 규칙을 설정합니다.
7. 네트워크 ACL(NACL): 서브넷 수준의 방화벽입니다. 보안 그룹보다 넓은 범위에서 트래픽을 제어합니다.

서브넷 설계:
- 퍼블릭 서브넷: 인터넷 게이트웨이로의 라우팅이 있어 인터넷에서 직접 접근 가능합니다 (웹 서버, ALB 등).
- 프라이빗 서브넷: 인터넷 직접 접근이 불가합니다. NAT 게이트웨이를 통해서만 아웃바운드 통신이 가능합니다 (DB, 애플리케이션 서버 등).
- 데이터베이스 서브넷: 프라이빗 서브넷의 하위 개념으로, 데이터베이스 전용으로 격리합니다.

VPC 피어링과 Transit Gateway:
- VPC 피어링: 두 VPC 간 프라이빗 IP를 사용한 직접 통신을 가능하게 합니다. 일대일 관계입니다.
- Transit Gateway: 여러 VPC와 온프레미스 네트워크를 중앙에서 연결하는 허브 역할을 합니다. 대규모 환경에 적합합니다.

VPC 엔드포인트:
- 게이트웨이 엔드포인트: S3, DynamoDB에 대한 프라이빗 접근을 제공합니다. 무료입니다.
- 인터페이스 엔드포인트: 대부분의 AWS 서비스에 대한 프라이빗 접근을 제공합니다. PrivateLink 기반이며 시간당 과금됩니다.

요금 체계:
- VPC 자체는 무료입니다.
- NAT 게이트웨이: 시간당 $0.045 + 데이터 처리 GB당 $0.045.
- VPC 엔드포인트 (인터페이스): 시간당 $0.01 + 데이터 처리 GB당 $0.01.
- 데이터 전송: 같은 AZ 내 무료, 다른 AZ 간 $0.01/GB, 인터넷으로 $0.09/GB (첫 10TB).
