Amazon S3 (Simple Storage Service) 개요

Amazon S3는 업계 최고의 확장성, 데이터 가용성, 보안 및 성능을 제공하는 객체 스토리지 서비스입니다.

주요 특징:
- 99.999999999% (11 9's)의 데이터 내구성을 제공합니다.
- 다양한 스토리지 클래스를 통해 비용을 최적화할 수 있습니다: S3 Standard, S3 Intelligent-Tiering, S3 Standard-IA, S3 One Zone-IA, S3 Glacier, S3 Glacier Deep Archive.
- 버킷(Bucket) 단위로 데이터를 저장하며, 각 객체(Object)는 최대 5TB까지 저장할 수 있습니다.
- 버전 관리(Versioning)를 통해 객체의 이전 버전을 보존할 수 있습니다.
- 서버 사이드 암호화(SSE-S3, SSE-KMS, SSE-C)를 통해 저장 데이터를 보호합니다.

사용 사례:
1. 데이터 레이크: 빅데이터 분석을 위한 중앙 저장소로 활용됩니다.
2. 백업 및 복원: 기업의 중요 데이터를 안전하게 백업합니다.
3. 정적 웹사이트 호스팅: HTML, CSS, JavaScript 파일을 호스팅하여 정적 웹사이트를 운영할 수 있습니다.
4. 콘텐츠 배포: CloudFront와 함께 글로벌 콘텐츠 배포에 활용됩니다.
5. 로그 저장: 애플리케이션 및 인프라 로그를 중앙에서 수집하고 분석합니다.

요금 체계:
- 저장 용량(GB/월), 요청 수(PUT, GET 등), 데이터 전송량에 따라 과금됩니다.
- 프리 티어에서는 12개월간 5GB Standard 스토리지, 20,000 GET 요청, 2,000 PUT 요청이 무료입니다.
